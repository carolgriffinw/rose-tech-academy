SQL Skills Every Data Analyst Needs

Data Analytics ROSE Tech Academy · 2025-03-01 · 6 min read

SQL — Structured Query Language — is the lingua franca of data. Nearly every data analyst role requires it, most data engineering positions demand fluency in it, and even business intelligence tools like Power BI and Tableau use SQL under the hood. If you are pursuing a career in data, mastering SQL is not optional. This guide covers the concepts that matter most in real interviews and real work.

1. SELECT, WHERE, and ORDER BY

Every SQL journey starts with retrieving data. Understanding how to filter rows with WHERE clauses and sort results with ORDER BY is the foundation everything else is built on. Pay particular attention to:

  • Filtering with multiple conditions (AND, OR, NOT)
  • Pattern matching with LIKE and wildcards
  • Handling NULL values with IS NULL / IS NOT NULL
  • Sorting on multiple columns and controlling ASC/DESC order

2. Aggregation: GROUP BY, HAVING, and Aggregate Functions

Aggregation is where SQL becomes genuinely powerful. The GROUP BY clause lets you summarise data across categories — total revenue by region, average order size by product, customer count by cohort. Aggregate functions you must master:

  • COUNT(), COUNT(DISTINCT column)
  • SUM(), AVG(), MIN(), MAX()
  • HAVING (filters on aggregated results, unlike WHERE which filters rows)

A classic interview question: "Write a query to find all customers who placed more than five orders last month." That's a GROUP BY on customer_id with a HAVING COUNT(*) > 5 and a date filter in the WHERE clause.

3. JOINs: The Most Important SQL Concept

Data rarely lives in a single table. JOINs are how you combine data across tables, and they are the source of the most common interview questions. You must understand:

  • INNER JOIN — Returns rows with matches in both tables. The most common join.
  • LEFT JOIN — Returns all rows from the left table, and matching rows from the right. Nulls fill unmatched right-table columns.
  • RIGHT JOIN — The mirror of LEFT JOIN. Less common but occasionally tested.
  • FULL OUTER JOIN — Returns all rows from both tables, with nulls where there is no match.
  • Self JOIN — Joining a table to itself. Common in hierarchical data (e.g., employee/manager relationships).
💡 Interview Tip

Draw a Venn diagram of each JOIN type before your interview. Interviewers frequently ask candidates to explain joins visually, and a clear mental model will give you confidence.

4. Window Functions

Window functions are the mark of an intermediate-to-advanced SQL practitioner. They allow calculations across a set of rows related to the current row, without collapsing the result like GROUP BY does. Key window functions:

  • ROW_NUMBER() — Assigns a unique row number within a partition
  • RANK() / DENSE_RANK() — Ranks rows within a partition
  • LAG() / LEAD() — Accesses previous/next row values
  • SUM() OVER() / AVG() OVER() — Running totals and moving averages

A common interview question: "Find the top 3 sales by product category." Without window functions, this requires a complex subquery. With RANK() OVER (PARTITION BY category ORDER BY sales DESC), it's five lines.

5. Subqueries and CTEs

Common Table Expressions (CTEs) with WITH clauses make complex queries readable and maintainable. They are preferred over deeply nested subqueries in production code and are increasingly tested in interviews. Practice refactoring a multi-level subquery into a CTE — it demonstrates both SQL skill and professional code habits.

6. Data Manipulation: INSERT, UPDATE, DELETE

Analysts mostly read data, but understanding how to write it is important for data quality work. Know how UPDATE with WHERE works, why DELETE without WHERE is dangerous, and when to use TRUNCATE vs DELETE.

Practice Resources

The best way to learn SQL is to write queries against real data. Free practice platforms include:

  • Mode Analytics SQL Tutorial (excellent free curriculum)
  • LeetCode Database problems (popular for interview prep)
  • StrataScratch (real interview questions from top companies)
  • SQLZoo (interactive exercises by topic)
